FPGA Sequence Detector and Logic Optimization

An 8 state Moore machine that detects a 4 bit pattern inside a serial stream, then a second pass that made the same behaviour measurably cheaper in hardware.

Gate input cost

The machine

A Moore finite state machine with 8 states, implemented with D flip-flops, detecting a specific 4 bit binary sequence anywhere inside a continuous stream.

Detecting inside a stream is what makes the state graph interesting. On a partial match that then breaks, the machine cannot simply restart from the initial state: it has to fall back to whichever state correctly represents the suffix it has already seen.

Cheaper in gates

Same behaviour, less hardware.

  • A custom Gray code state assignment means only one state bit changes per transition, which reduces the number of terms each next state equation has to cover.
  • Karnaugh map simplification on the resulting equations cut total gate input cost from 83 to 63.
  • That is a 24 percent reduction in circuit complexity with no change in what the machine does.

Verification

Timing and state transitions were checked in functional simulation in Quartus Prime, walking the machine through partial matches, broken matches and back to back detections rather than only the happy path.
